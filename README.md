# clawit-site

Public pages for the Clawit app, served by GitHub Pages (branch `main`, root).

- `index.html` + `assets/` — landing page, the App Store marketing URL.
- `privacy/` — privacy policy, linked from the app and the store listings.
- `imprint/` — imprint (Impressum), linked from the app, the privacy policy and the store listings.

Source of truth is `docs/` in the (private) app repository; this repo is a published copy.
